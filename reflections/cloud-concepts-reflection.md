# Cloud Concepts Reflection

Cloud computing has become an important part of my daily life, even though I often use it without realizing it. As an IT student, learning about cloud concepts helped me understand how many of the applications I rely on every day work behind the scenes. It also made me appreciate how cloud technology makes data accessible, secure, and easy to share.

Three cloud services that I use regularly are Google Drive, Canva, and Messenger. Google Drive is a Software as a Service (SaaS) application because it allows me to store, organize, and share files without managing any servers or infrastructure. It uses a Public Cloud deployment model since anyone with a Google account can access it over the internet. Canva is also SaaS because it provides online design tools that users can access through a web browser without installing software. It is deployed on the Public Cloud because it is available to anyone who creates an account. Messenger is another example of SaaS because Meta manages the application, servers, and updates while users simply send messages and make calls. It also uses the Public Cloud since it serves millions of users through the internet.

I also learned why Git and GitHub are essential in cloud projects. Version control is important because cloud infrastructure files and application code are constantly updated. Without version control, changes could easily be lost or overwritten. Git records every modification, making it possible to review previous versions or restore files when needed. GitHub makes collaboration easier by allowing developers to work on separate branches, review each other's changes through pull requests, and merge approved updates into the main project. This reduces mistakes, keeps projects organized, and ensures that everyone is working with the latest version of the code. Overall, this lesson showed me that cloud computing and version control are valuable skills that I will continue to use throughout my studies and future career in information technology.
