## Reflection Questions

1. **Which cloud provider offers the broadest range of services?**  
   Amazon Web Services (AWS) offers the broadest range of services among all cloud providers. As the market pioneer launched in 2006, it features over 200 fully featured services covering computing, storage, machine learning, and IoT. Its extensive mature ecosystem makes it the top choice for complex, large-scale deployments.

2. **Which provider best integrates with Microsoft technologies?**  
   Microsoft Azure best integrates with enterprise Microsoft technologies. It provides seamless ecosystem compatibility with tools like Windows Server, Active Directory, SQL Server, and Office 365. This allows organizations with existing Microsoft software licenses to migrate smoothly using hybrid cloud features.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**  
   Google Cloud Platform (GCP) is widely recognized for its core strengths in Artificial Intelligence and Kubernetes. Since Google originally developed Kubernetes, GCP offers leading-edge container management through Google Kubernetes Engine (GKE). Additionally, its AI/ML suite, powered by Vertex AI and custom TPU infrastructure, delivers robust capabilities for data analysis.

4. **Which cloud platform would you personally choose and why?**  
   I would personally choose Amazon Web Services (AWS) due to its comprehensive documentation and extensive global community support. Its mature infrastructure and wide array of native cloud services make it ideal for building, scaling, and managing diverse software applications effectively.
